    Clé pour commander le bot depuis cet appareil

    Comment créer cette clé (une seule fois, 2 minutes)
    1. Ouvre github.com → Fine-grained token.
    2. Token name : appli-bot · Expiration : 1 an.
    3. Repository access : Only select repositories → bot-trading-demo.
    4. Permissions → Repository : Actions = Read and write, Contents = Read-only.
    5. Generate token, copie-le et colle-le ci-dessus. Fais pareil sur ton téléphone et ta tablette (la même clé).

    La clé reste uniquement sur tes appareils. Elle ne permet que de lancer le bot et lire ses résultats. Ne l'envoie à personne.

    Comment ça marche

    Toutes les 15 minutes environ, le bot se connecte à ton compte démo Capital.com (argent fictif), regarde les dernières bougies, applique la stratégie, puis achète, vend ou ne fait rien. Chaque décision est notée dans le Journal, et chaque position dans Ordres.

    Le même signal s'affiche sur ton graphique TradingView grâce au script tradingview/strategie_demo.pine.

    Pour changer la stratégie ou les réglages, demande-le à Claude dans le projet.
