      Clé pour commander le bot depuis cet appareil

      Comment créer cette clé (une seule fois, 2 minutes)
      1. Ouvre github.com → Fine-grained token.
      2. Token name : appli-bot · Expiration : 1 an.
      3. Repository access : Only select repositories → bot-trading-demo.
      4. Permissions → Repository : Actions = Read and write, Contents = Read-only.
      5. Generate token, copie-le et colle-le ci-dessus. Même clé sur ton téléphone et ta tablette.

      La clé reste uniquement sur tes appareils. Elle permet seulement de lancer le bot et de lire ses résultats. Ne l'envoie à personne.
